# Contributing

## Definition of Done (DoD)
A change is merge-ready only when:
- Design doc exists (or explicit waiver)
- Implementation plan exists (or explicit waiver)
- Tests added/updated for behavior changes
- Verification commands run and results included in PR
- Risks/tradeoffs captured

## Branch naming
- `feat/<ticket>-<slug>`
- `fix/<ticket>-<slug>`
- `hotfix/<ticket>-<slug>`

# Engineering Playbook

## Required gates
1. **Design approval before implementation**
2. **TDD for behavior changes** (red → green → refactor)
3. **Root-cause debugging** (evidence → hypothesis → test → fix)
4. **Verification evidence before done**
5. **Isolated feature branch/workspace**

## Recommended gates
- Plans broken into 2–5 minute executable steps
- Two-stage review: spec compliance, then code quality
- Parallel work only for independent streams

## Definition of done
- Requirements satisfied
- Tests pass
- Verification commands and outcomes documented
- Risks/tradeoffs noted

# Agent Startup Contract

When instructed to "use the template", do this in order:

1. Read `ENGINEERING_PLAYBOOK.md`.
2. Create/update a design doc from `docs/templates/design-template.md`.
3. Create/update an implementation plan from `docs/templates/implementation-plan-template.md`.
4. Execute in small steps with tests-first for behavior changes.
5. Before claiming done, run and report verification commands.
6. Fill PR evidence sections completely.

Do not skip gates unless the user explicitly approves a bypass.

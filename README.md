# Agent Org Dev Template

Template repository for consistent, high-quality, agent-assisted software delivery.

## What this template gives you
- Design-before-code workflow
- Implementation planning template
- TDD + verification gates
- Debugging incident template
- PR evidence checklist
- Lightweight compliance CI

## Quick start
1. Create a new repo from this template.
2. Read `AGENTS.md` and `ENGINEERING_PLAYBOOK.md`.
3. Run `scripts/start-feature.sh <ticket> <slug>`.
4. Open a PR using the built-in template.
